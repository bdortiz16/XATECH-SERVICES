# XATECH Services

Página web oficial de **XATECH Services** — soluciones tecnológicas a la medida.

## Contenido

- `index.html` — Landing page autocontenida (HTML + CSS + JS en un solo archivo, sin dependencias externas).

## Secciones de la página

- **Inicio (Hero)** — Presentación y llamados a la acción.
- **Servicios** — Desarrollo web y apps, soporte TI, nube, ciberseguridad, consultoría y redes.
- **Nosotros** — Propuesta de valor y estadísticas.
- **Contacto** — Formulario de contacto (frontend; pendiente conectar a un backend o servicio de correo).

## Cómo verla

Abre `index.html` directamente en el navegador, o sirve el directorio con cualquier servidor estático:

```bash
python3 -m http.server 8000
# luego visita http://localhost:8000
```

La página es responsive (funciona en móvil y escritorio) y no requiere instalación ni build.
